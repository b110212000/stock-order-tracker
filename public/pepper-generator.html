ORDERLEAD · 一次性設定

一鍵產生 Cloudflare 私人金鑰

不用電腦、不用安裝程式。金鑰由這支手機的瀏覽器安全隨機產生，不會傳送到任何伺服器，也不會存入網站資料庫。

🔒 產生的是 32 bytes 安全隨機值，編碼成 Cloudflare 需要的 43 字元 base64url。不用輸入你的 Gmail 密碼。

接下來貼到 Cloudflare

  1. 開啟 Cloudflare Dashboard。
  2. 進入 Workers & Pages → orderlead-api → Settings → Variables and Secrets → Add。
  3. Type 選 Secret；Variable name 填 PASSWORD_PEPPER。
  4. Value 貼上剛複製的金鑰，按 Deploy。
  5. 到 Workers Builds 對最新的 main 版本選擇 Retry deployment。

請不要截圖或分享金鑰。完成後直接關閉本頁；不用傳金鑰給我。這是 OrderLead 登入密碼使用的私密金鑰，與 MLB 共用 Gmail SMTP 是兩件事。
