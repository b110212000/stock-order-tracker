# OrderLead 版本規劃

|---|---|
| v1.0.0 | React 基礎、RWD、主題、PWA、GitHub Actions |
| v1.1.0 | 股票追蹤新增/編輯、IndexedDB |
| v1.2.0 | 訂單領先評級、證據與歷史分析 UI |
| v1.3.0 | 真實買賣紀錄、多批持股與成本配對 |

| v1.5.0 | 價格提醒 UI、資料匯出還原 |

| v1.7.0 | 一次性 Gmail 成交回報匯入、待核對資料與安全合併 |
| v1.8.0 | 一鍵批次核對、可選費用估算、重複與 FIFO 防呆 |
| v1.8.1 | 修復暫存無法批次清除、支援 ZIP 匯入、取代待核對資料 |
| v1.9.0 | 第一關驗收：只顯示 2024 年起富邦 Gmail 歷史現買／可配對現賣；其餘功能隱藏 |
| v1.10.0 | 第一關延伸：FIFO 配對各筆可計算現賣毛損益；未知成本不計入總計 |
| v1.10.1 | 自動接續舊 Gmail 暫存與空白頁面防護 |
| v1.10.2 | 修復 PWA 舊版快取及 Service Worker；保留所有本機交易資料 |
| v1.11.0 | 第一關個股分組視圖：左買右賣、配對損益、郵件計算剩餘股數 |
| v1.12.0 | 個股收合毛損益摘要（Issue #18）與多條件排序（Issue #19） |
| v1.13.0 | 第一關通用化：手動第一筆買進、手動買賣、取消年份限制、匯入合併去重（Issue #20） |
| v1.13.1 | App UI：底部「交易／設定」＋設定更新／修復（Issue #21）；交易頁左匯入右新增、精簡與 Toast（Issue #22） |
| v1.14.0 | 設定下載通用交易 JSON 範例（Issue #23）；交易頁移除舊暫存恢復及自動搬移（Issue #24） |
| v2.0.0 | 後端、行情、GPT API、真正 Web Push |

每一版對應一個 GitHub Issue。v1.x 只做前端，v2.0.0 必須經同意才啟動。新功能次版號 +1；UI/Bug 修正修訂號 +1；主版號需明確核准。未完成當期版本不開始下一版。


> 自 v1.9.0 起所有後續功能凍結，只有使用者驗收歷史交易表後才規劃第二關。不以 `v2.0.0` 自動啟用後端。
