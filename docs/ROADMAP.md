每一版對應一個 GitHub Issue。v1.x 只做前端，v2.0.0 必須經同意才啟動。新功能次版號 +1；UI/Bug 修正修訂號 +1；主版號需明確核准。未完成當期版本不開始下一版。


> 自 v1.9.0 起所有後續功能凍結，只有使用者驗收歷史交易表後才規劃第二關。不以 `v2.0.0` 自動啟用後端。
